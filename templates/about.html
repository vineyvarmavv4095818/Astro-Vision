About AstroVision

AstroVision is a space exploration web application that allows users to explore NASA's Astronomy Picture of the Day and discover fascinating content about our universe.

🚀 What can you do with AstroVision?

NASA APOD

Explore NASA's Astronomy Picture of the Day along with its description and date.

Space Search

Search for astronomy-related topics and discover relevant space images.

Favorites

Save your favorite APOD images and videos and manage them using the SQLite database.

Telescope Gallery

Explore fascinating images captured by space telescopes such as JWST and Hubble.

🛠 Technology Used

Python Flask SQLite Jinja2 HTML CSS REST API

🎯 Purpose of the Project

This project was developed to gain practical experience in Python web development, Flask, REST API integration, database management, Jinja2 templating and frontend design.
